# ບົດລາຍງານການປັບປຸງໃບສົ່ງຕໍ່ຄົນເຈັບ (A4 & PDF Print Redesign)

## ສະຫຼຸບການແກ້ໄຂ ແລະ ປັບປຸງທັງໝົດ

ໄດ້ດຳເນີນການແກ້ໄຂ ແລະ ປັບປຸງລະບົບໃບສົ່ງຕໍ່ຄົນເຈັບສຸກເສີນ A4 (`ReferralA4Print.tsx` ແລະ `index.css`) ໃຫ້ຖືກຕ້ອງ ແລະ ຄົບຖ້ວນຕາມທີ່ທ່ານໄດ້ແນະນຳ:

### 1. ຕາປະທັບຊາດລາວ (National Emblem of Laos) & ຄຳຂວັນປະເທດ
- **ກາໝາຍຊາດລາວ (Emblem of Laos 1991–2025)**: ໄດ້ສ້າງເປັນ Vector SVG ຄວາມລະອຽດສູງຝັງໃນລະບົບ (ສະແດງຮູບ ພະທາດຫຼວງສີຄຳ, ຮວງເຂົ້າສຸກເຫຼືອງອ້ອມຮອບ, ກົງຈັກອຸດສາຫະກຳ, ເຂື່ອນໄຟຟ້າ, ເສັ້ນທາງປູຢາງ ແລະ ແພໂບສີແດງ) ຢູ່ເຄິ່ງກາງຢ່າງສະຫງ່າງາມ ແລະ ຄົມຊັດທຸກຂະໜາດ.
- **ຄຳຂວັນປະເທດ (Centred Motto)**:
  ```
  ສາທາລະນະລັດ ປະຊາທິປະໄຕ ປະຊາຊົນລາວ
  ສັນຕິພາບ ເອກະລາດ ປະຊາທິປະໄຕ ເອກະພາບ ວັດທະນະຖາວອນ
             ***==***
  ```

### 2. ຫົວຂໍ້ຍ່ອຍຊ້າຍ-ຂວາ (Subheader) & ການຕັດເສັ້ນຂີດ
- **ເບື້ອງຊ້າຍ**:
  - `ພະແນກສາທາລະນະສຸກ: ແຂວງຈຳປາສັກ`
  - `ໂຮງໝໍເມືອງ: [ຊື່ໂຮງໝໍເມືອງ]`
- **ເບື້ອງຂວາ**:
  - `[REF-ID] - HN: [HN-CODE]`
  - `ໂທ: [ເບີໂທ] Triage: [ລະດັບສຸກເສີນ]` (ຕໍ່ເລີຍໃນແຖວດຽວກັນ)
- **ຕັດຂີດເສັ້ນອອກ**: ຕັດເສັ້ນຂີດກັ້ນຍາວໃຕ້ຫົວຂໍ້ອອກຕາມທີ່ລະບຸ.

### 3. ການຕັດຕົວຫຍໍ້ປະກັນສຸຂະພາບ
- ຕັດຕົວຫຍໍ້ `(NHI/ປສຊ)` ຫຼື `(ປສຊ)` ອອກຈາກຊ່ອງປະກັນສຸຂະພາບ/ກອງທຶນ ໃຫ້ສະແດງພຽງແຕ່ຊື່ເຕັມທີ່ສະອາດຕາ ເຊັ່ນ: `ກອງທຶນປະກັນສຸຂະພາບແຫ່ງຊາດ`.

### 4. ໝວດ II: ການບົ່ງມະຕິພະຍາດຫຼັກຕໍ່ເລີຍ
- ປັບປຸງຫົວຂໍ້ໝວດ II ເປັນ:
  `II. ຂໍ້ມູນອາການ ແລະ ການບົ່ງມະຕິ: [ຊື່ພະຍາດ/ການບົ່ງມະຕິ]` ຕໍ່ເລີຍໃນແຖວດຽວກັນ ເພື່ອປະຢັດພື້ນທີ່ ແລະ ອ່ານງ່າຍ.

### 5. ຕັດຂໍ້ຄວາມ Oxygen Device ທີ່ບໍ່ກ່ຽວຂ້ອງອອກ
- ຕັດຂໍ້ຄວາມ `* Oxygen Device: ET-Tube No. 7.5 with Ambu-bag (O2 10L/min)` ອອກຈາກລະບົບທັງໝົດ.

### 6. ໝວດ V: ການປິ່ນປົວເບື້ອງຕົ້ນຕໍ່ເລີຍ
- ປັບປຸງເປັນ: `ການປິ່ນປົວເບື້ອງຕົ້ນທີ່ໄດ້ໃຫ້ໄປແລ້ວ: [ລາຍລະອຽດການປິ່ນປົວ]` ຕໍ່ເລີຍຢ່າງຕໍ່ເນື່ອງ.

### 7. ປັບປຸງບ່ອນລາຍເຊັນລຸ່ມສຸດ (Signatures)
- **ເບື້ອງຊ້າຍ**:
  - ປ່ຽນເປັນ: **`ຜູ້ອຳນວຍການ`**
  - ຕັດຊື່ໂຮງໝໍອອກ
  - ບໍ່ມີຊື່ທ່ານໝໍ ແລະ ບໍ່ມີເສັ້ນຂີດກ້ອງ, ເວັ້ນຊ່ອງຫວ່າງສະອາດໄວ້ສຳລັບລາຍເຊັນ ແລະ ປະທັບກາ.
- **ເບື້ອງຂວາ**:
  - ປ່ຽນເປັນ: **`ທ່ານຫມໍສົ່ງຄົນເຈັບ`**
  - ຕັດຊື່ໂຮງໝໍອອກ
  - ບໍ່ມີຊື່ທ່ານໝໍ ແລະ ບໍ່ມີເສັ້ນຂີດກ້ອງ, ເວັ້ນຊ່ອງຫວ່າງສະອາດໄວ້ສຳລັບລາຍເຊັນ.

### 8. ແກ້ໄຂການພິມ ແລະ ດາວໂຫຼດ PDF ໃຫ້ພໍດີ A4 1 ໜ້າ (Single-page A4)
- ປັບແຕ່ງ CSS Print Styles (`@page { size: A4 portrait; margin: 8mm 10mm; }`, `page-break-after: avoid;`) ແລະ ໄລຍະຫ່າງ (padding/leading) ຂອງຕາຕະລາງ ແລະ ຂໍ້ຄວາມ ເຮັດໃຫ້ເອກະສານທັງໝົດ **ບັນຈຸພໍດີ 1 ໜ້າເຈ້ຍ A4 ພໍດີ 100% ໂດຍບໍ່ມີໜ້າທີ 2 ເຫຼືອເກີນອອກມາ**.
- ປຸ່ມ **"ດາວໂຫຼດ PDF (A4)"** ແລະ **"ພິມເອກະສານ (Print A4)"** ເຮັດວຽກຜ່ານ Native Browser Print Engine ເຊິ່ງສາມາດເລືອກ "Save as PDF" ໄດ້ທັນທີ ໂດຍຕົວໜັງສື ແລະ ຮູບກາໝາຍຊາດຄົມຊັດສູງ (Vector PDF) ບໍ່ມົວ ແລະ ບໍ່ຕິດ Error.
